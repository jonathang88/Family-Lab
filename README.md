# Family Lab — Documentación del laboratorio (sanitizada)

Repositorio con la documentación sanitizada del laboratorio *Family* (WordPress). Contiene las anotaciones, resumen de técnicas usadas y recomendaciones de seguridad. Está pensado para fines educativos y de demostración en entornos controlados.

**Importante:** No subir datos reales, contraseñas ni claves privadas.
